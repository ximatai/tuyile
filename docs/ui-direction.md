# 界面规范

界面面向中大型桌面，沿用已认可的工程蓝、A 主工作台与 B 折叠窄轨。保留基础响应式能力，不新增手机专用布局。

## 布局与导航

- 左侧导航与项目列表、中央画布、右侧创作面板构成主工作台；侧栏宽208px，收起为72px窄轨，保留可访问名称与 Ant Tooltip。
- 展开/收起使用约220ms栏宽与内边距过渡，文字轻微淡入，允许连续反向操作；遵循系统减少动态效果偏好。
- 桌面顶部状态栏高48px，正文滚动时保持可见。工作台剩余高度由同一高度变量计算，画布与右侧参数区按各自边界滚动。
- 主导航为项目、图库、提示池、收藏、额度；管理员另有账号管理、模型服务。
- 右上角用户名下拉菜单提供修改密码和退出登录。修改密码使用原位弹窗，不改变当前URL或主面板；关闭后清空输入并返回触发按钮焦点。保存前先保存画布，失败留在弹窗；成功后所有设备重新登录。

## 创作与执行反馈

- 右侧分直接创作和 Agent 页签，提示词与参考图优先。示例覆盖已有提示词先确认，风格作为可编辑提示词显示，不偷偷增加模型参数。
- 参考图提供缩略图、移除、上传及画布选图引用；普通选中画布图片不自动替换引用，数量受模型与个人策略约束。
- 模型列表支持按模型/服务搜索和默认标记，同名不同服务独立选择。分辨率/比例联动，比例配轮廓并显示实际像素；质量用快速草稿、标准、高质量命名。所有选项遵循产品、模型能力和个人策略的交集。
- 主操作固定可达，任务提交立即反馈；排队、生成、实际已保存张数与终态持续显示在按钮旁及画布可视区。读状态失败和提交结果未知单独提示，不虚构百分比、预计时间或成功状态。
- Agent 采用方案一：对话内展示可审阅的步骤摘要、参考图、依赖和预计图片预留，明确点击修改才编辑，确认后才执行；确认与额度反馈固定可达。Skill 是创作方法，计划是本次执行方案。
- 结果支持原图预览和参数复用。复用只填草稿，覆盖先确认；历史失效模型要求重新选择服务，不自动映射同名项。

## 控件与密度

标准输入、选择器、表格、上传、提示、确认及弹层由 Ant Design 提供。共享组件负责 tokens 和布局，不重写通用控件。

常规控件32px、辅助按钮28px，正文13px、辅助12px、页面标题22px、区域标题16px、卡片/弹层标题14px。保留已有更小控件的有效点击范围，不做全局缩放。侧面板宽360–440px、卡片内边距16px、表单间距10–12px。

让分区和控件名称解释操作，避免重复副标题与段落。必要的风险、失败、费用预留与确认说明就近可见；补充规则使用可点击和可用键盘关闭的 Popover，图标操作用 Tooltip / Dropdown。

长内容用成熟组件的滚动、Collapse 或可展开段落；长表单 Drawer 使用固定 footer。图库强调图片和就近复用/下载，画布展示完整原图与来源关系，不把示意图中的占位标题、数字或虚构功能做成产品事实。

## 验证

主要核对1440×900和1920×1080，包括侧栏展开/收起、项目切换、长表单、较长计划、确认按钮、预览、弹窗、键盘、Esc、焦点返回与滚动边界。检查真实功能与构建版CSP，不以静态效果图替代端到端验收。
