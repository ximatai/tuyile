# 已确认的 UI 方向

以用户认可的 A（project sidebar）效果图为主，收起导航借鉴 B（canvas first）的窄轨。工程蓝继续沿用。用户最新确认：优先中大型屏幕，不再投入小屏幕专用适配。

## 桌面工作台

- 单一紧凑顶栏：品牌、当前项目、保存状态、额度和账户入口，避免重复标题挤占创作区域。
- 左侧固定导航和项目列表，当前项目明确高亮；折叠为 B 的图标窄轨，中央区域随之扩展。
- 中央占据主要空间，图片是视觉主体；完整工作台使用浅色点阵画布、清楚的选中边框和就近的图片操作，避免把整个创作区做成管理表单。
- 右侧白色创作面板，提示词和参考图优先；模型、尺寸、质量和张数紧凑排列，次要设置折叠。提交主操作固定可见，参数区可滚动；额度反馈与按钮不重叠。
- 不把效果图中的占位文字、示例图片、未确认的工具按钮当成新增业务要求；实际能力按产品基线和阶段计划交付。

## 实现与核对

标准控件使用 Ant Design；共享组件只负责工程蓝主题、布局和业务组合。画布使用 React Flow，不重新实现通用控件或图形引擎。

主要核对 1440×900、1920×1080，并检查更宽桌面上的空间利用。核对展开/折叠、项目切换、参数滚动、主按钮可见、图片预览和焦点操作。现有基础响应式可以保留，手机专用抽屉和切换不再作为后续验收要求。

阶段 2 交付后台创作的最小结果界面，不把它当作完整画布的最终视觉稿；阶段 3 按 A 的整体构图整合完整工作台，不重新另起视觉方案。
