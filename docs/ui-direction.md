# 界面规范

界面面向中大型桌面，采用工程蓝、三栏主工作台（A）与折叠窄轨（B）。保留基础响应式能力，不新增手机专用布局。

## 布局与导航

- 左侧导航与项目列表、中央画布、右侧创作面板构成主工作台；侧栏宽208px，收起为72px窄轨，保留可访问名称与 Ant Tooltip。
- 展开/收起使用约220ms栏宽与内边距过渡，文字轻微淡入，允许连续反向操作；遵循系统减少动态效果偏好。
- 桌面顶部状态栏高48px，正文滚动时保持可见。工作台剩余高度由同一高度变量计算，画布与右侧参数区按各自边界滚动。
- 主导航为项目、图库、提示池、收藏、额度；管理员另有用户管理、模型服务。
- 右上角用户名下拉菜单提供修改密码和退出登录。修改密码使用原位弹窗，不改变当前URL或主面板；关闭后清空输入并返回触发按钮焦点。保存前先保存画布，失败留在弹窗；成功后所有设备重新登录。

## 创作与执行反馈

- 右侧分直接创作和 Agent 页签，提示词与参考图优先。示例覆盖已有提示词先确认，风格独立选择，描述按需展开编辑，切换不改写创作需求或抢走输入焦点。服务端提交时组合需求与风格，历史可查看风格及实际提交文本，复用分别恢复；旧记录不按文本反推风格。
- 参考图提供缩略图、移除、上传及画布选图引用；普通选中画布图片不自动替换引用，数量受模型与个人策略约束。
- 模型列表支持按模型/服务搜索和默认标记，同名不同服务独立选择。尺寸/比例联动，菜单直接显示实际像素，仅精确匹配的通用规格附带720p、1440p或4K名称；菜单只列当前比例的可用尺寸，实际像素与尺寸标题同行，比例配轮廓；质量用快速草稿、标准、高质量命名。所有选项遵循产品、模型能力和个人策略的交集。
- 常用规格与格式直接可见，张数使用单一选择器；固定规格模型不显示只读宽高，自由尺寸模型提供折叠的自定义尺寸。额度摘要与详情入口同行，零预留不额外标记；后台执行、取消计费与中断不续跑保留一句，详细说明通过邻近帮助按钮查看。成功反馈合并为已生成张数。主操作固定可达，任务提交立即反馈；排队、生成、实际已保存张数与终态持续显示在按钮旁及画布可视区。读状态失败和提交结果未知单独提示，不虚构百分比、预计时间或成功状态。
- Agent 使用对话内计划卡：对话内展示可审阅的步骤摘要、参考图、依赖和预计图片预留，明确点击修改才编辑，确认后才执行；确认与额度反馈固定可达。Skill 是创作方法，计划是本次执行方案。
- 结果支持原图预览和参数复用。复用只填草稿，覆盖先确认；历史失效模型要求重新选择服务，不自动映射同名项。

## 控件与密度

标准输入、选择器、表格、上传、提示、确认及弹层由 Ant Design 提供。共享组件负责 tokens 和布局，不重写通用控件。

常规控件32px、辅助按钮28px，正文13px、辅助12px、页面标题22px、区域标题16px、卡片/弹层标题14px。保留已有更小控件的有效点击范围，不做全局缩放。侧面板宽360–440px、卡片内边距16px、表单间距10–12px。

让分区和控件名称解释操作，避免重复副标题与段落。必要的风险、失败、费用预留与确认说明就近可见；补充规则使用可点击和可用键盘关闭的 Popover，图标操作用 Tooltip / Dropdown。

长内容用成熟组件的滚动、Collapse 或可展开段落；长表单 Drawer 使用固定 footer。图库强调图片和就近复用/下载，画布展示完整原图与来源关系，不把示意图中的占位标题、数字或虚构功能做成产品事实。

## 验证

主要核对1440×900和1920×1080，包括侧栏展开/收起、项目切换、长表单、较长计划、确认按钮、预览、弹窗、键盘、Esc、焦点返回与滚动边界。检查真实功能与构建版CSP，不以静态效果图替代端到端验收。

参考图与私有截图留在忽略目录；用于公开文档的图片须按[贡献指南](../.github/CONTRIBUTING.md)审查内容、元数据和授权。

画布空白处左键拖动即可平移，空格键临时平移；工具栏提供选择与拖拽切换，选择模式允许移动节点及Shift框选，拖拽模式拖动图片也只平移视图。任务与结果抽屉按任务展示独立卡片，卡片包含状态、可展开提示词、缩略图与就近操作；抽屉统一滚动，长内容不撑开页面。

画布图片节点以完整图片占满节点区域，去除重复标题、底部文字栏和卡片底板；预览、下载、引用和参数复用使用图片上的图标操作，悬停或键盘聚焦时显示，保留Tooltip与可访问名称。图片不裁切，缩放手柄和来源关系保持可用。

图片操作通过React Flow节点浮层定位，按钮保持28px屏幕尺寸，不随画布缩放。图片屏幕宽度小于160px或高度小于48px时收为“更多”菜单，保留预览、下载、引用和复用。“更多”按钮位于图片内部右上角，鼠标移入按钮时保持显示；选中、悬停或聚焦时可见，浮层靠近边缘时调整位置，菜单由Ant Design处理。

任务与结果抽屉使用图片优先的紧凑网格，按行从左到右排列，空间不足换行，少量卡片不拉伸铺满。卡片保留一行需求、状态与张数；提示词、风格、模型、时间、尺寸与复用设置收进任务详情。图片悬停或聚焦显示下载、引用与更多操作，删除收进更多菜单。失败、待核验与取消入口就近可见，整个抽屉统一纵向滚动。

任务详情Popover顶部合并模型与时间，尺寸规格使用紧凑标签，提示词为主体、风格使用浅底分区，复用操作置于底部。长内容在正文内滚动，Esc关闭并将焦点返回详情按钮。

侧栏底部展开/收起使用低强调的图标按钮，以Tooltip和可访问名称说明动作，不常显文字。品牌图标与两行品牌文字整体上下对齐。

额度入口统一放在顶栏账户菜单左侧，显示今日可用与预留数量，点击查看明细；创作侧栏不重复占位。成功任务以自动消失的完成通知提供查看任务入口，不常驻成功状态；进入项目不重复提醒历史完成任务。执行中、失败、待核验及提交待确认保留可见反馈。后台执行与计费说明收进生成按钮旁的信息入口。

创作编辑区字段标题统一字号、字重与颜色。参考图上传入口使用“上传参考图”，已引用图片以64px缩略图单行横排，超出宽度横向滚动，不增加区域高度；名称由图片替代文本和悬停提示提供，移除按钮置于缩略图右上角。

直接创作参数使用模型/质量、比例/尺寸、张数/格式三行双列，模型选中值展示已知简称、完整身份保留在下拉选项和悬停提示中。参考图上传采用图标按钮。提示词按窗口和面板尺寸测量剩余空间，在140—280px间适配；增加参考图、展开风格时保持输入框高度，编辑字段统一滚动，生成操作紧随参数并始终可见。

尺寸像素值仅在尺寸下拉框内展示，标题旁不重复显示。

风格选择与编辑图标同排，编辑在Popover内完成，草稿经“应用”生效，取消或Esc不改变当前风格。修改预设保留原名称并展示“已修改”，编辑器支持恢复预设草稿；风格变化不修改创作需求，也不挤压其输入区域。

生成参数只展示模型有效能力与个人策略允许的选项，只有一个合法值时锁定。历史失效参数仍允许切换到合法值，不把失效值锁死。

模型服务页以并排的对话模型池和图片生成模型池为主体，默认模型置顶。每组提供添加入口，候选目录、目录获取和手动登记仅在对应添加Drawer中出现；服务地址、接入配置和停用操作收进管理服务Drawer。添加只修改待发布配置，统一发布后生效；候选目录不再常驻主页面。

模型能力Drawer提供“恢复默认”，仅恢复抽屉中的系统推荐草稿，不改变模型身份、开放开关及默认模型选择。应用和发布仍是独立步骤。对话模型的协议与输入输出预算收进高级设置，已知模型自动匹配参考图理解能力。

图片模型尺寸配置提供“按模型范围开放”和“仅开放指定尺寸”两种模式，替代逗号输入。指定尺寸使用可搜索多选，常用候选按模型及配置上限过滤，支持校验后添加自定义宽高；指定列表不得为空，降低上限后失效的尺寸需移除或调整。

### 用户管理

用户策略并入用户管理：列表展示账号、管理员／用户角色和状态，支持按用户名筛选；点击“管理”打开右侧抽屉，集中管理账号操作、额度限制及允许的图像模型。关闭抽屉前确认放弃未保存修改。模型服务页不再展示用户策略。内部角色标识保持 admin/member。

用户抽屉默认只展示每日图片额度、以 GB（1024³ 字节）计的存储上限、模型权限。模型权限明确选择全部开放模型或指定模型。调用次数、并发、排队、尺寸和质量限制置于默认折叠的高级设置；隐藏设置保留原值。

用户抽屉中的重置密码生成一次展示的随机临时密码，由管理员自行交付；管理员自己的重置按钮禁用。临时密码登录后展示独立改密页，改密成功撤销会话并返回登录。后端同样限制临时会话访问业务，不能仅依赖页面跳转。

每日图片额度使用“不限额”复选框，不向管理员暴露内部的-1。勾选时数字输入禁用；取消勾选恢复本次编辑前的数值或100。状态栏、额度详情和Agent确认统一展示不限额，消费和预留数量仍正常记录。

用户抽屉以用户名为标题，角色与状态紧随标题展示；自身账号标注“当前账号”，不显示不可用的管理操作。他人账号的密码重置及启停收进标题右侧更多菜单，停用操作以危险项展示并保留确认。

用户列表顶部采用单行工具栏：搜索框与“新增用户”按钮并排，用户名输入在新增用户弹窗中完成。成功后关闭弹窗并展示仅本次可见的临时密码，列表刷新。

用户搜索覆盖全部账号，切换搜索条件重新分页；搜索框输入与当前查询分离并短暂防抖。未保存用户配置的保护覆盖路由返回、退出和刷新，不仅限于关闭抽屉。

“我的额度”以每日可用图片、已用空间两块并排概览为主体；调用与并发限制收进额度详情。使用记录按提交时间、生成张数、状态列表展示，点详情再查看提示词与图片；活动任务自动刷新。空间管理统一跳转图库，额度页不再重复展示图片管理列表。

提示池顶部只保留管理创作预设入口；模板卡片标题与分类并排，正文可展开，底部对齐“使用”和收藏图标。“使用”悬停或点击展开“我的项目”，选择后直接带入完整提示词；菜单支持搜索、分页及新建项目后继续使用，无项目时仍可打开。浮层使用标准 Ant Design Popover/Menu，靠边自动调整位置，Escape 可关闭，鼠标移入菜单保持展开。

管理员从提示池标题右侧“管理创作预设”进入维护页。顶部搜索标题/分类与“新增提示词”同排，表格展示标题、分类、状态；新增与编辑在抽屉完成，默认不上架，勾选“上架，所有用户可见”后保存发布。下架沿用同一开关，不提供永久删除。未保存编辑覆盖抽屉关闭、路由切换与浏览器离开保护；并发冲突保留草稿并要求重新读取。普通用户不显示管理入口，接口仍独立校验权限。

提示池主体左侧为分类面板，全部分类清空筛选；复选框支持多选和再次点击取消，多个分类取合集，全部取消时显示全部。分类目录来自完整已上架模板，筛选在服务端分页之前执行；切换筛选重新从第一页读取，目录不会因筛选结果而缩减。

“我的项目”浮层的搜索入口为标题右侧图标按钮，默认隐藏搜索框，点击展开并聚焦；再次点击收起并清空查询，恢复完整项目列表。

“我的项目”标题右侧并排放置新建项目加号与搜索图标，底部不再重复放置新建按钮。

“我的收藏”采用左侧分组复选面板与右侧卡片网格，分组多选取合集，全部取消或点击“全部分组”显示全部；分组查询在服务端分页前执行。顶部只保留新增提示词入口。图片卡片支持原图预览，提示词卡片直接呈现正文；卡片底部“使用”复用项目菜单，图片可在菜单中选择加入画布或用作参考。编辑与移除收进更多菜单，移除仍确认且不删除原图。

普通操作反馈统一使用共享浮动提示：成功约 2 秒，失败约 5 秒，同一位置只展示一条，后续反馈替换前一条，不挤占页面布局。表单校验与保存失败保留在当前表单，保留输入供重试；查询不可用、资源引用限制、任务结果待确认、画布冲突等持续影响操作的状态保留紧凑提示条。生成完成的任务通知继续保留查看任务入口。文案直接说明结果，避免重复解释。

任务详情在创作区与额度页共享字段、失败说明和操作规则。失败说明使用业务语言，说明已保存结果及下一步，不直接展示内部错误码。已结束且有参数快照的任务即使零输出也能复用设置；只恢复可编辑草稿，不自动生成。活动或待核验任务不开放复用设置。结果图片统一提供下载与更多菜单（预览、作为参考图、复用设置），删除仅在已有删除入口的场景提供；已删除原图不展示图片操作。额度页继续创作返回任务所属项目，重新校验项目访问，历史模型参数仍受当前权限与能力限制。

风格选择按公共风格、我的风格分组，保留无风格、自定义风格与当前快照。编辑浮层中“应用”仅影响当前创作，“保存为我的风格”创建个人副本；个人项可保存修改或删除。公共风格与提示词管理位于同一页面，通过标签页切换，列表直接展示，新增与编辑才打开抽屉，新增默认不上架，名称、描述、上架开关为主要字段，未保存编辑有离开保护。

快捷提示词固定一行，最多三个短按钮加“更多”，长标题省略且不提供长正文tooltip。我的收藏优先，无文字收藏时回退公共提示词（推荐优先）；更多用Popover承载“我的收藏／公共提示词”标签、搜索、分组及结果正文预览，不导航离开画布。Escape关闭并返回触发按钮，取消替换保留输入与浮层。管理员在提示词编辑中勾选推荐，列表标注“推荐”，浮层展示全部已上架公共项，推荐项排在前面；未上架项不展示。

提示词选择浮层不重复设置标题，标签直接表达来源；点击条目标题、正文或空白区域选用，正文的展开／收起独立操作，选择文字不触发选用，不为每条重复展示“使用”按钮。仅在有多个分组或已启用筛选时显示分组选择；分类已筛选时不重复展示同一分组标签。

提示词链路：公共条目一键收藏，已收藏以实心图标表示并防重复；浮层收藏与整条选用分别操作。创作需求标题旁提供收藏当前内容入口，仅填写标题和可选分组；分组采用Ant AutoComplete选择已有值或输入新值。提示池/收藏使用相同的标题及正文搜索。管理端推荐标记显示为“优先展示”。刷新、登录或离开项目再返回恢复已自动保存的需求、风格、参数和参考图；从其他页选用不同提示词先确认替换。移除收藏确认仅描述收藏本身。

草稿正常编辑时自动保存，不增加常驻保存按钮；加载成功前不显示空白可写表单。仅失败或冲突时显示就地提醒，冲突提供“加载最新草稿”“保留当前版本”，覆盖均需明确确认。直接创作和Agent各自保留输入，参考图共享；提交后不清空，相同进行中输入禁用重复提交。

加载服务器草稿期间仍可编辑，新输入优先保留，出现新编辑时不替换表单。历史任务复用即使文字相同，只要生成参数不同也要确认；取消后保留原参数。

Agent 空态以居中图标和简短流程提示引导，输入与参考图组成底部创作卡片；常用输入优先，创作设置通过独立浮层展开，不挤压提示词高度。规划可用次数与设置入口同行，零预留不显示，执行规则按需查看；生成计划与确认执行保持两个明确阶段，无计划时不占用确认操作区。计划出现后默认收起输入卡片，通过“继续聊想法”展开，保留原草稿并优先为计划阅读留出空间；确认执行旁始终保留计费与中断说明入口。

Agent 澄清回复只呈现对话，输入保持可见且不提供执行按钮。可执行方案以作品名称、自然语言设计方向及张数／横竖版／质量摘要展示，不在默认卡片暴露原始提示词、模型 ID 或工具版本；原提示词与技术参数分别按需编辑。调整方案回到对话并保留输入，未保存的手工调整需先保存再继续沟通。确认执行始终独立于规划，澄清不预留图片额度。
