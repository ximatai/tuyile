# Tuyile 产品基线

更新日期：2026-11-01。本文是当前业务范围来源；技术实现见[架构设计](architecture.md)，交付与验证状态见[交付状态](delivery-roadmap.md)。

## 1. 产品定位

- 中文名：图一乐；英文展示名：Tuyile；工程名称：tuyile。
- 服务器上的多用户图片创作工具；采用 PostgreSQL 与一个独立后台 Worker，接受其部署维护成本，不以重启续跑或多 Worker 作为首版要求。
- 先搭好中期基础，做好分层与模块切割，保留长期演进空间，再尽快上线；不提前建设完整长期平台。
- 本次未对商标、域名或名称独占性作出结论。

## 2. 用户与内容边界

- 首版面向少量指定用户，由管理员创建账号；不开放注册、邮件服务或社交登录。
- admin/member 两种角色。管理员维护账号、配额、允许模型、统一服务 Key 和全局 Agent Skills。
- 每个用户拥有一个 personal workspace，workspace 是服务端权限边界。预留成员关系；首版不开放团队、邀请和共享。
- 管理员没有查看他人图片、提示词、对话或结果的产品权限。服务器维护者可能接触底层存储，不宣称端到端加密。
- 项目、画布、资产、生成记录、对话、计划、任务与收藏均归属工作区。个人图片可在自己的不同项目间复用，不新增生图计次。
- 公共提示池由管理员维护，普通用户只读共享；管理员可新增、编辑、上架及下架，新增默认不上架。收藏和分组私有，保存正文快照，公共模板后续修改或下架不覆盖已有收藏；公开素材不构成商业授权素材包。
- 匿名访问私有资源返回 401，角色不足返回 403，外部资源 ID 越权统一返回 404。

## 3. 账号、会话与任务授权

| 行为                | 会话                           | 已确认任务                                              |
| ------------------- | ------------------------------ | ------------------------------------------------------- |
| 关闭/刷新页面、断网 | 不视为账号撤销                 | Worker 正常运行时继续执行                               |
| 普通退出登录        | 仅撤销当前设备会话             | 继续执行；任务由账号持有                                |
| 密码重置/修改       | 撤销全部会话与连接             | 停止后续调度，尽力取消在途调用                          |
| 停用账号            | 禁止登录与新任务，撤销全部会话 | 停止后续调度，尽力取消在途调用                          |
| 重新启用账号        | 允许重新登录                   | 保留内容，不复活已取消的旧任务                          |
| 用户显式取消任务    | 不改变会话                     | 不再启动后续调用，在途尽力取消                          |
| API 单独重启        | 由持久化会话重新验证           | Worker 与数据库正常时继续执行                           |
| Worker 故障或重启   | 不必改变浏览器会话             | 原运行任务允许失败/部分完成，不自动续跑；已保存输出保留 |

关闭页面和普通注销均不取消已确认任务。用户确认执行前应看到后台执行、取消可能仍计费和中断允许失败的说明。任务与状态入库用于查询/归属/结算，不承诺任意后端、数据库或文件系统故障下持续执行或数据不丢失。

首版使用有界后台队列和一个 Worker；执行并发满时允许等待，队列满才拒绝新提交。前端通过 HTTP 轮询查看状态；持久化事件流、租约、接管和可靠重放不纳入首版。

未确认的 Agent 草案不因关页自动执行。确认请求的网络响应丢失时，客户端通过稳定幂等键查询结果，不自动生成另一个新请求。

首个管理员通过受控初始化命令建立，不设置默认密码或匿名管理员创建接口。新增账号和管理员重置他人密码均生成一次展示、24 小时有效的随机临时密码，仅保存密码哈希，登录后必须改密才能访问业务。管理员不能在管理入口重置自己；部署侧管理员恢复保留一次性链接。由管理员通过自己的渠道交付，不自动发送消息。普通注销不影响其他设备。

## 4. 创作与额度规则

- 支持直接生图、参考图改图、Agent 先规划后确认执行、画布编辑、Gallery、提示池与收藏。
- 创作辅助提供快捷示例、独立选择与编辑的风格提示、分辨率/比例与实际像素、快捷张数及画布选图一键引用。替换已有提示词先确认，普通画布选中不自动改写参考图；规格受模型能力和个人策略约束，辅助选择本身不调用模型。切换风格不改写创作需求；提交时固定风格文本并由服务端组合，任务保留原始需求、风格和实际提交文本。Agent 将独立风格作为规划指导，确认的步骤提示词完整表达执行内容。
- 统一使用管理员配置的模型服务，普通用户只能选择允许模型；Key 与 Base URL 不下发给普通用户。
- 管理员维护多个命名服务连接，从服务获取候选模型，分别发布对话与图像生成模型池；每个非空开放池指定一个默认模型。模型身份包含服务，用户只能选择全局开放且符合个人策略的模型。候选目录刷新不自动开放或移除已发布模型，能力由管理员明确声明。不做自动路由、故障切换或比价；已接受任务绑定不可变配置版本。
- 图片按成功且本地持久化的张数计次，包括中间基准图。上传参考图和复用已有图片不扣生图次数，但占存储。
- 上游已调用或收费但无本地成功图片，只记录尝试和可得的费用证据，不直接增加图片已用次数。未知结果暂留预留，核验确认无法取得图片后释放；人工声明上游成功不能凭空计作本地成功输出，晚到证据不得重复结算。已成功保存后用户删除原图不返还次数。
- Agent 每次用户规划/修改请求预留一次，在首次上游调用前提交计次；调用开始后失败也不返还。内部重试和一次格式修复共用预算，不重复扣规划次数。
- 图片整单、Agent 整份计划原子预留；不足则整单拒绝，不自动分拆或降质。失败/未启动取消释放相应图片预留，部分成功按实际成功张数结算。
- 结果未知时保留相关预留，持久化并对账，不自动重复生成。Worker 中断可将任务标为失败/部分完成，但不代表上游没有消费；已确认成功输出保留，明确未启动部分可释放，未知部分待核验。用户显式重试是新的准入操作。
- 预留固定归属创建日，跨日完成仍结算原日。跨日重试按新操作计入新日。降低上限不撤销已接受预留，但阻止新的超额准入。
- 账号所有设备共享额度、频率和并发限制；时间由服务端确定，默认 Asia/Shanghai 每日 00:00 切换。
- 初始默认策略，管理员可调：普通用户每日 100 张图、管理员图片不限额，每日 50 次规划；单图最长边 2048、最多 4194304 像素、最高 high；单次最多 4 张，Agent 整计划最多 16 张；用户生图/规划并发各 1，全局初始各 2；每用户每分钟最多 6 次新生图提交，每日最多 300 次上游生图尝试（按实际发送尝试的统计日限制，包含内部重试，不以原日图片预留绕过当日上限）。
- 初始每用户存储 2 GiB；参考图单次上传最多 20 MiB，仅 PNG/JPEG/WebP，最长边 8192、最多 32000000 像素，验证真实格式并受限解码。
- 既有内容超出新上限时保留，禁止新增，仍可下载与释放空间。全局磁盘低水位暂停新任务。
- 最多一次明确安全的自动网络重试，最多一次 Agent 格式修复；未知请求不重发，不能通过内部修复重置 token/步骤/超时预算。
- 次数额度与费用估算不能保证账单金额上限。不可获得的模型用量记 unknown；估算记录价格版本，不冒充真实账单。

## 5. 项目、画布与删除

- React Flow 承载自有版本化 CanvasDocument，不把前端图形状态作为执行权威。
- 每项目独立画布、对话和计划；画布支持平移/缩放、选图、移动/尺寸调整、复制、删除节点、分组/解除、对齐、图片名称与分组标题原位重命名、撤销/重做和只读来源关系。
- 画布获得焦点时提供全选、复制/粘贴、创建副本、撤销/重做、删除和取消选择快捷键；输入与弹层保留原生行为。节点剪贴板仅限当前登录会话的同项目内存快照，节点复制仅向系统剪贴板写临时标记，图片内容及资产元数据不外写；支持拖入本地图片及粘贴截图；退出清除，粘贴复用原图且不新增生图计次。
- 节点删除与撤销只改变文档，不删除原图、不发起/取消模型调用、不返还额度。删除分组保留子节点。
- 保存带 revision，冲突保留本地内容，支持重新加载或另存，不静默覆盖；首版不做实时协作。
- 项目有活动或待核验任务时禁止删除；取消已请求但未确认完成仍受保护。可删除时清除项目、画布和对话内容，Gallery 原图及必要用量审计保留。
- 原图被授权范围内的文档、对话、计划、收藏或活动任务引用时禁止删除，提示本人可查看的引用位置。检查与引用变更必须事务互斥。
- 以中大型桌面屏幕为设计与验收重点。保留现有基础响应能力，不将手机专用交互作为首版交付门槛。
- 视觉采用工程蓝；整体以 A 布局为主，侧栏收起采用 B 的窄导航。页面遵循[界面规范](ui-direction.md)。

## 6. 存储与本地交付

- 首版图片为私有本地文件，通过授权服务访问；不启用公开云对象、公开作品链接或 Codex OAuth 回退。
- 功能与合成数据备份恢复在本地隔离环境验证。数据库版本化 schema 迁移仍显式执行。
- 自动回归使用合成账号和Provider，不调用付费模型。真实模型测试须单独确认费用和范围，生成内容与凭据不进入Git。
- 提供 HTTPS 代理及部署说明，公开上线不在当前执行范围。

## 7. 首版范围控制

不纳入公开注册、用户自带 Key、支付订阅、永久删除账号及全部数据、团队共享、公开作品链接、素材市场、实时多人协作、视频、完整白板或专业图像编辑器。首版不做多 Worker 接管、运行任务重启续跑或可靠事件流；中期目标也不自动包含多机高可用、跨地域容灾或无停机升级承诺；可用性和备份恢复目标在部署设计时明确。

## 8. 技能与工具扩展边界

采用版本化、可注册、可组合、可停用的技能与工具机制。技能表达可复用的创作指导、输入要求及工具依赖；工具提供实际执行能力。首版管理员管理声明式技能，开发者实现可信工具并在部署时注册，不支持在线安装第三方代码、任意脚本或插件市场。

技能不得绕过平台授权、用户确认、额度和工具白名单。已确认计划绑定技能、工具定义及服务配置版本；普通停用只阻止新计划使用，紧急撤销阻止后续尚未发出的调用，在途尽力取消。未来扩展不应要求重写核心任务、资产和结算流程，但不提前建设运行沙箱或通用插件平台。当前技术契约见[架构设计](architecture.md)。

模型能力按已知模型文档上限、管理员开放声明和个人策略分别约束；当前已校准Sunburst/Flare的格式及尺寸边界，依据与未知模型限制见[模型能力校准](model-capabilities.md)。用户控件不提供被排除的选项，只有一个合法值时锁定；服务端预留额度前及实际执行前校验，不依赖前端禁用。

风格分公共风格与个人风格：管理员在创作预设页维护公共风格，默认未上架；个人风格按工作区隔离，仅本人增删改。初始五个公共风格通过迁移0019导入，不在启动时覆盖。每个范围最多200个有效风格。选择或应用只改变当前创作；保存到个人风格才持久化。公共风格编辑保存为个人副本。任务保留名称与文本快照，不因源风格修改、下架或删除而改变。

默认公共风格保持五款：真实摄影、商品棚拍、平面插画、海报视觉、简洁3D。描述区分表现方式并让主体、场景及文字要求由创作需求决定。0020仅校准未经编辑、仍上架的原始默认项，保留管理员修改、个人副本及历史任务快照；这次校准未通过付费模型逐项生成验证。

创作区快捷提示词优先展示本人最近收藏的文字提示词，最多三条；图片收藏不参与，无文字收藏时使用已上架公共提示词，管理员推荐项优先，快捷栏仍最多三条。更多入口在原位弹出收藏/推荐选择面板，支持按标题和正文搜索、分组筛选及分页；使用只替换创作需求，已有不同内容先确认，风格和参考图保持不变，不自动提交生成。

公共提示词支持一键收藏；收藏来源按工作区去重，正文保持独立快照，编辑私人副本不影响公共内容。创作区可直接收藏公共条目或当前需求，收藏、编辑、移除及管理员保存后同步相关选用缓存。提示池与私人收藏支持正文/标题搜索和分类/分组联合过滤。从提示池带入已有不同需求时先确认替换。

创作草稿按项目自动保存到服务端，停止输入约1秒后保存，切页和退出补存；刷新、关页或重新登录后恢复直接创作与Agent各自的需求、风格和生成参数，以及共享参考图与当前模式。提交后保留输入，恢复不执行模型调用，相同进行中输入禁止重复提交。未保存成功时保留当前输入并提示，切页补存失败则留在原页；立即刷新或关页尚未保存的内容时触发浏览器离开保护。多标签页用独立草稿版本拒绝静默覆盖，允许显式加载或覆盖。草稿参考图纳入引用保护，删除项目时清理草稿与引用。正文不写浏览器持久存储。

画布支持批量上传PNG/JPEG/WebP图片作为素材，不要求已配置图片模型，不自动加入参考图。直接创作或Agent入口上传参考图时，同一资产也加入当前画布；画布素材可通过选中引用或图片操作设为参考图。上传只占存储，不增加图片生成次数；参考图仍受数量及模型能力约束。移除引用不移除画布节点，删除节点不删除原图或参考图。新上传采用上述行为，历史参考图不自动补入画布。

画布支持一次拖入最多20张本地PNG/JPEG/WebP图片，或在画布聚焦时用系统粘贴快捷键导入截图。仅处理用户触发的原生剪贴板事件，不主动读取剪贴板、不申请读取权限、不导入HTML或远程图片URL。复制节点时仅写入随机临时标记，节点快照仍在当前会话与项目内存中；标记匹配则粘贴节点，否则导入剪贴板图片。超过20张时整批拒绝并提示，输入控件与弹层保持原生行为，上传限制、存储计量和引用保护沿用现有规则。

画布上传与拖放支持每批最多20张，逐张上传并显示进度。批前验证全部文件的类型、单张20MiB与剩余节点容量，任一不符则整批拒绝；传输或服务端验证中途失败时停止后续文件，保留已加入的图片，结果不明不自动重传。新节点按当前视口附近三列寻找空位，保留24画布单位间隔并避开已有图片及分组，不移动原有节点；坐标空间不足明确提示，原图可从图库找回。每张加入独立撤销，参考图入口仍遵守现有数量和模型能力限制。

后台生成结果自动加入画布时复用同一避让规则，避免晚到结果与新上传素材重叠；坐标范围内无法放置时保留未放置结果及回执，用户平移视图后再尝试放置。

右侧创作面板采用右侧锚定、临时展开和可固定模式，默认固定展开。本机仅记住固定偏好（旧折叠偏好不再使用），不保存临时展开状态或创作正文。折叠不卸载直接创作或Agent表单，保留草稿、未保存方案、当前模式和后台任务。折叠时关闭浮层、禁用隐藏控件，主动收起时将焦点归还展开按钮；展开重新测量输入布局，保持画布viewport不变。图片引用、复用设置和上传失败会自动展开，普通选图不展开。桌面沿用现有A布局与工程蓝控件，不增加拖拽调宽。

固定模式占据原右栏宽度；取消固定后画布仅为40px窄栏留位，临时展开以覆盖层锚定右侧，不改变画布viewport或宽度。窄栏悬停300ms唤出，未操作时移出200ms收起；点击入口或开始编辑后保持展开，点击真实画布或按Escape收起。画布点击继续完成选图或拖动，不被阻断；输入法组字时不处理收起，浮层优先处理Escape。图钉只切换固定偏好；点击右侧当前面板图标只隐藏面板，重新打开继续沿用固定模式。输入、Agent手工方案和后台任务保留；引用/复用/错误只临时展开，不自动固定。纯悬停不抢占Agent输入焦点。

右侧40px工具条始终保留“直接创作”和“Agent”两个独立图标，使用Ant按钮与提示，标明当前打开的入口。点击不同图标打开并切换面板，点击已打开的同一图标隐藏；隐藏不改变固定偏好。固定模式隐藏后通过图标重新打开仍固定停靠；未固定模式在图标悬停时延迟预览对应面板。两份创作草稿与未保存Agent方案保持独立保留，不新增模型调用。

右侧面板不再重复展示“直接创作／Agent”标签切换，切换统一通过常驻双图标工具条。顶部使用28px单行标题栏，仅显示当前面板名称及邻近的小号无边框图钉，顶部留白8px；收起统一使用右侧当前面板图标，Agent清空操作放在规划对话区。保留现有模式与草稿，画布快捷键和Escape分层行为保持不变，不因标题展示变化触发模型调用。

## 9. 新用户示例

管理员验收并发布一个含 A、B 两张文生图及 A＋B→C 参考合成图的示例项目。仅之后新增的 member 获得独立私有副本；首次完成改密并登录后进入示例。保留三张图片的原始提示词、规格及来源连线，作为示例记录展示，不创建虚假生成任务、不调用模型、不扣生成次数；文件占用用户存储额度。已有用户不补发，删除示例不重建，修改副本不影响模板或其他用户。初始化失败不影响账号创建和登录，可由本人或管理员重试。

画布支持纯文本便签：标题、最多4000字符正文、透明/浅黄/浅蓝/浅绿底色，支持拖动、缩放、混合分组、对齐、复制、删除、撤销重做和自动保存。双击正文编辑，Enter换行，Ctrl/Cmd+Enter完成，Esc恢复本次编辑前正文；输入中的全选、复制、粘贴保持原生行为。编辑实时保存，画布撤销合并连续正文编辑；期间有新图片到达等独立操作时，按发生顺序保留各自的撤销记录。

直接创作与Agent共享有序的“引用文案”，从当前项目画布多选最多8条；可以查看原便签、排序、移除以及预览组合需求。引用源修改影响之后的新提交，移除引用不删除便签，源被删或正文为空时明确阻止新提交。服务端在提交事务内从本项目读取正文并固定快照；需求、文案和风格组合最多12000字符。已提交任务/规划保留原快照，重复请求不会重读新正文；Agent确认使用规划时快照。结果显示独立的“文案”来源连线。文案是创作指导，不保证模型逐字排版，不提供富文本、HTML渲染或把文本直接合成到图片的功能。

复用带文案的历史任务时，将当时文案快照带入可编辑需求并清除当前文案链接，避免引用已经改动的源便签；用户可以自行改回引用画布中的最新文案。
