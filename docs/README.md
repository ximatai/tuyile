# 项目文档

| 已交付范围、验证基线和后续安排   | [交付状态](delivery-roadmap.md)                                           |
| 工程协作与安全约束               | [仓库说明](../AGENTS.md)                                                  |

维护规则：业务变化更新产品基线，技术变化更新架构，命令变化更新开发或运维说明，交互变化更新界面规范。阶段结束只在交付状态中保留结论和证据入口，过程记录归档，不把反复追加的进度日志放入日常指南。截图、日志、凭据及生成素材留在 Git 外。
