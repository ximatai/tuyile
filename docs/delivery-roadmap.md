# 当前能力与后续方向

当前为面向小规模指定用户的自托管版本，以小规模指定用户和桌面图片创作为目标。已有本地自动回归、构建版浏览器、HTTPS与合成数据备份恢复验证；这些结果不等于生产环境承诺或远程CI已经通过。

## 已实现

- 外部 Agent 可通过项目级 MCP 授权读取画布、批量编排并提交生图。网页提供 Codex 连接指引及版本同步，任务和用量沿用现有后台执行链路。

- Image 2.6 Sunburst / Flare 静态图片能力校准、版本展示及可选复杂度，贯通草稿、Agent、任务快照和历史复用，并提供版本化参考价格。
- 探索/精修推荐、Agent保持要求、方案版本选择及部分执行，成功作品显式复用后继续衍生，稳定步骤依赖与幂等确认。
- SVG 单件生成、静态受限预览、私有原件下载/ZIP、图库/收藏/画布管理、显式栅格参考副本与来源关系。画布支持静态 SVG 修订回流、原稿比较和逐稿导出。独立记录生成作者配置和用量。
- 圈选/画笔修改、服务端草稿与待确认提交恢复、前后比较、下载修改稿、保留原图再试和用修改稿接续。
- 将画布选稿或标注结果连同文案和保持要求带入 Agent 衍生，按独立上下文规划，确认后只执行选定的新增步骤。

- 管理员全平台及按用户的今日/本月/自统计以来token统计、OpenAI版本化参考费用估算及缺失用量标识。

- 用户管理今日图片/规划额度及只读生成作品预览，管理员作品访问审计。

- 账号激活、密码重置/修改、会话撤销、个人工作区与权限隔离。
- 管理员发布版本化新用户示例，独立私有副本、示例提示词与来源、首次登录引导及幂等失败重试。
- 后台图片生成与参考编辑、单Worker有界队列、额度/存储及未知结果核验。
- 项目图片堆叠封面卡片、项目画布、带revision保存、冲突保留、分组与撤销重做；创作草稿自动保存与跨刷新、登录恢复。
- 画布纯文本便签、混合编排、有序引用文案及提交快照；直接创作与Agent共享引用，失效引用显式阻止新提交。
- Agent对话内计划审阅、手动修改、确认与依赖执行；版本化技能/可信工具。
- 私有图库与收藏、公共提示池及管理员新增/编辑/上下架维护、跨项目复用、下载/ZIP导出。
- 命名模型服务、对话/图像开放池、个人策略及脱敏管理信息。
- 紧凑固定顶栏、可折叠导航、持续生成反馈，以及账户菜单和原位密码弹窗。

两款 Image 2.6 模型已在 OpenAI 官方 Images API 通过 1024×1024 PNG、圈注修改及 SVG 抽样验证。测试参数与覆盖边界见[模型能力校准](model-capabilities.md#真实服务抽样验证)。

## 当前限制

不提供公开注册、团队共享、实时协作、支付、公开作品链接、插件市场、多Worker接管或重启自动续跑。模型能力由管理员声明，某次真实模型验证不证明全部服务与规格兼容。

开发版可能出现 React Flow 的 flushSync / ResizeObserver 提示，构建存在共享块体积提示。

## 后续方向

### 工程计划状态

外部 Agent 治理分为客户端验收、项目活动记录和最近编辑撤销三个阶段。Codex CLI 0.167.0 已在隔离的本机 HTTPS 环境验证工具发现、读写画布、合成生图与撤销令牌。目标部署环境的连通性及 Codex 桌面端仍待试点验收。

[图片创作能力升级专项治理方案](image-creation-governance.md)五个阶段已完成并通过自审、独立审查与相应验证，文档保留范围和治理决策作为历史依据。GIF 仍为后续方向。

优先完善可复现问题、实际操作体验、维护性与部署验证。涉及功能扩展时先说明业务价值和边界，按[贡献指南](../.github/CONTRIBUTING.md)提交完整、聚焦的变更，不提前建设通用平台。

源码和镜像的发布检查见[发布指南](releasing.md)。
