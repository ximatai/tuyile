# 当前能力与后续方向

当前为早期自托管版本，以小规模指定用户和桌面图片创作为目标。已有本地自动回归、构建版浏览器、HTTPS与合成数据备份恢复验证；这些结果不等于生产环境承诺或远程CI已经通过。

## 已实现

- 账号激活、密码重置/修改、会话撤销、个人工作区与权限隔离。
- 后台图片生成与参考编辑、单Worker有界队列、额度/存储及未知结果核验。
- 项目画布、带revision保存、冲突保留、分组与撤销重做。
- Agent对话内计划审阅、手动修改、确认与依赖执行；版本化技能/可信工具。
- 私有图库与收藏、公共提示池、跨项目复用、下载/ZIP导出。
- 命名模型服务、对话/图像开放池、个人策略及脱敏管理信息。
- 紧凑固定顶栏、可折叠导航、持续生成反馈，以及账户菜单和原位密码弹窗。

## 当前限制

不提供公开注册、团队共享、实时协作、支付、公开作品链接、插件市场、多Worker接管或重启自动续跑。模型能力由管理员声明，某次真实模型验证不证明全部服务与规格兼容。

开发版仍可能出现React Flow的flushSync / ResizeObserver提示，构建存在共享块体积提示；与构建版错误检查分开处理。未发布公共镜像、npm包或托管服务。

## 后续方向

优先完善可复现问题、实际操作体验、维护性与部署验证。涉及功能扩展时先说明业务价值和边界，按[贡献指南](../CONTRIBUTING.md)提交完整、聚焦的变更，不提前建设通用平台。

开源材料、源码扫描与发布限制见[开源准备检查](open-source-readiness.md)和[发布指南](releasing.md)。后续公开托管、二进制分发及生产部署分别完成对应准备，不共享或复用本地凭据。

内部实施与验收日志保留在Git仓库的docs/archive中，不属于当前待办，也不随公共源码包分发；此处只维护现行能力与方向。
