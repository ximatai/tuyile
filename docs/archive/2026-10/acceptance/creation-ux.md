## 交付行为

- 直接创作、Agent 规划设置和计划步骤编辑共用能力感知参数控件。初次加载选用允许的默认配置；后续切换模型或服务、策略轮询更新均保留草稿，不自动换服务、降质量、改尺寸或删参考图。不兼容项就近提示并阻止新提交；结果未确认的原键重试仍使用原输入。
- 画面规格显示横版/竖版/方形、比例和实际像素。模型声明固定尺寸时只列允许项；自由尺寸按模型与个人边长/像素限制提供常用比例，也可在“更多设置”精确填写。质量、格式、张数和编辑/生成模式同时受能力及个人策略约束，后端仍是准入权威。
- 参考图紧跟提示词，上传、画布及图库引用使用同一草稿来源，支持附件预览和逐张移除。隐藏页签不重复挂载附件图片；已填草稿保留。画布“作为参考图”留在当前创作模式；结果“继续修改”进入直接创作草稿。
- 画布双击或图片菜单、任务结果和附件使用 Ant Design 原图预览，保留缩放、旋转及 Esc 关闭，采用即时开合。结果菜单/任务明细可回填提示词、尺寸、质量、格式、张数、参考图和原模型选择；已有正文或参考图时先确认替换，所有复用都不自动执行。
- 已结束且存在结果的任务可复用设置；活动或待核验任务不提供可执行的复用操作。池条目 ID 保持服务身份；历史任务没有条目 ID 或条目已移除时，要求明确选择新模型及服务，不按同名模型猜测。依赖上一步的 Agent 结果从持久化来源关系补齐实际使用的参考图，列表按批次读取，历史输入和请求哈希不改写。
