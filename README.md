# 图一乐 · Tuyile

面向指定用户的 AI 图片创作工作台。

产品采用服务器多用户形态，支持个人项目、图片生成与参考图创作、Agent 计划、私有图库和后台任务。首版以一个 Worker 消费有界队列，正常运行时关页、刷新和普通注销不影响执行；Worker 中断允许任务失败，进度通过轮询查看。视觉方向为工程蓝，工作台采用左侧项目导航、中央画布、右侧创作面板，侧栏可收起。
